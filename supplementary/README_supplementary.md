# Supplementary Analyses

This directory documents supplementary analyses generated by scripts in `scripts/analysis/`.

The supplementary analyses include:

## Mask Probability Sweep

`scripts/analysis/mask_probability_sweep.py`

Validation-only experiments for selecting the optimal lead-masking probability. Tests multiple masking probabilities (p=0.1, 0.2, ..., 0.9) to determine which best preserves 12-lead performance while improving robustness.

## Multi-Seed Sensitivity Analysis

`scripts/analysis/multiseed_sensitivity.py`

Runs training with multiple random seeds (e.g., seed 42, 123, 456) to assess variance in model performance and ensure robustness of reported results.

## Hypertrophy-Class Analysis

`scripts/analysis/hypertrophy_class_analysis.py`

Generates PTB-XL hypertrophy-class (HYP) specific precision, recall, and F1-score summaries. The hypertrophy diagnostic class is a unique feature of PTB-XL and may benefit differently from lead-masking strategies.

## Checkpoint Integrity Verification

`scripts/analysis/verify_checkpoint_integrity.py`

Audits saved checkpoints for:
- Model state dictionary completeness
- Architecture signature consistency
- Reproducibility of model loading across systems

## Experiment Artifact Compilation

`scripts/analysis/compile_experiment_artifacts.py`

Collects final metrics, figures, logs, and audit outputs into a single reproducibility package suitable for sharing or archival.

## Note

These supplementary analyses are not required for reproducing the main paper results but are recommended for:

- Validating robustness across multiple random seeds
- Justifying hyperparameter choices (e.g., masking probability)
- Understanding class-specific behavior
- Ensuring reproducibility across different hardware/software configurations
